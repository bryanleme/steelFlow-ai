# Guia de publicação no LinkedIn

## Arquivos prontos

- texto: `docs/LINKEDIN_POST.md`;
- apresentação: `docs/SteelFlow_AI_LinkedIn_Carousel.pptx`;
- roteiro editável: `docs/LINKEDIN_CAROUSEL.md`.

## Como publicar

1. Inicie uma nova publicação no LinkedIn.
2. Escolha a opção de adicionar documento e envie o arquivo PowerPoint.
3. Use como título do documento: **SteelFlow AI — quando o modelo não sabe, ele para**.
4. Cole o conteúdo de `docs/LINKEDIN_POST.md` como legenda.
5. Confira a prévia das páginas e publique.

O LinkedIn aceita documentos PowerPoint e PDF. Se a prévia alterar a diagramação,
exporte o arquivo para PDF sem mudar o conteúdo.

## Revisão antes de publicar

- mantenha explícito que os dados são sintéticos;
- não apresente o resultado como ganho real de produção;
- não descreva o protótipo como controle de máquina;
- preserve o resultado que não atingiu a meta;
- confirme que o repositório público aponta para a versão mais recente.
